# 🎬 Netflix India — Homepage Clone

A pixel-perfect, responsive clone of the **Netflix India** homepage built using **HTML and CSS** only — no frameworks and no JavaScript.

---

## 🖥️ Preview

🌐 **Live Demo:**  
https://buildsbytanmay.github.io/Netflix-Home-Page-Clone/

> Features a hero section with a background image, alternating feature sections with embedded videos, an FAQ accordion layout, and a complete footer inspired by the official Netflix India landing page.

---

## ✨ Features

- 🎯 **Hero Section**
  - Full-viewport background image with a dark overlay
  - Email sign-up form
  - Sign In button

- 📺 **Feature Sections**
  - Four alternating image and text sections
  - TV viewing
  - Mobile downloads
  - Multi-device support
  - Kids profiles

- 🎥 **Embedded Videos**
  - Autoplay
  - Muted
  - Looping `.m4v` videos displayed inside device mockups

- ❓ **FAQ Section**
  - Expandable question cards
  - Hover effects

- 📱 **Responsive Design**
  - Optimized for desktop, tablet, and mobile devices
  - Breakpoints at **959px**, **599px**, and **450px**

- 🌐 **Language Selector**
  - English / हिन्दी toggle
  - Available in both the navigation bar and footer

- 📄 **Footer**
  - Multi-column link layout matching the original Netflix footer

## 🚀 Getting Started

No build tools or additional dependencies are required.

### Clone the Repository

```bash
git clone https://github.com/your-username/netflix-clone.git
cd netflix-clone
```

### Run the Project

Open `index.html` in any modern web browser.

## 📱 Responsive Breakpoints

| Screen Width | Behavior |
|--------------|----------|
| **≤ 959px** | Smaller logo, centered content, and stacked footer columns |
| **≤ 599px** | Collapsed language selector in the navigation bar |
| **≤ 450px** | Adjusted video overlay positioning on device mockups |

---

## 🎨 Design Highlights

- Font stack similar to Netflix:
  - `Netflix Sans`
  - `Helvetica Neue`
  - `Segoe UI`
  - `Roboto`
  - `Ubuntu`
- Netflix Red (`#E50914`) used consistently for buttons and focus outlines.
- Floating label animation on the email input field.
- Dark semi-transparent hero overlay using `rgba(0,0,0,0.7)`.
- Section separators styled with `rgb(46, 44, 44)`.
