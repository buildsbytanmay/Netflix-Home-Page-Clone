# 🎬 Netflix India – Homepage Clone

A pixel-perfect, responsive clone of the **Netflix India** homepage built using **HTML** and **CSS** only. This project recreates the look and feel of the official Netflix India landing page without using JavaScript or any external frameworks.

---

## 🌐 Live Demo

**View the Project:**  
https://buildsbytanmay.github.io/Netflix-Home-Page-Clone/

---

## ✨ Features

### 🎯 Hero Section

- Full-screen background image with a dark overlay
- Email sign-up form
- Sign In button

### 📺 Feature Sections

- Four alternating image and text sections
- TV viewing experience
- Mobile downloads
- Multi-device streaming
- Kids profiles

### 🎥 Embedded Videos

- Videos displayed inside device mockups
- Autoplay
- Muted
- Looping playback

### ❓ FAQ Section

- Expandable question cards
- Hover effects

### 🌐 Language Selector

- English / हिन्दी language toggle
- Available in both the navigation bar and footer

### 📄 Footer

- Multi-column footer layout inspired by the official Netflix website

### 📱 Responsive Design

Optimized for desktop, tablet, and mobile devices with breakpoints at:

- **959px**
- **599px**
- **450px**

## 🚀 Getting Started

No installation, build tools, or additional dependencies are required.

### Clone the Repository

```bash
git clone https://github.com/your-username/netflix-clone.git
cd netflix-clone
```

### Run the Project

Simply open `index.html` in any modern web browser.

## 📱 Responsive Breakpoints

| Screen Width | Layout Behavior |
|--------------|-----------------|
| **≤ 959px** | Smaller logo, centered content, stacked footer columns |
| **≤ 599px** | Collapsed language selector in the navigation bar |
| **≤ 450px** | Adjusted video overlay positioning inside device mockups |

---

## 🎨 Design Highlights

- Font stack inspired by Netflix:
  - `Netflix Sans`
  - `Helvetica Neue`
  - `Segoe UI`
  - `Roboto`
  - `Ubuntu`
- Consistent use of Netflix Red (`#E50914`) for buttons and focus outlines
- Floating label animation for the email input field
- Dark hero overlay using `rgba(0,0,0,0.7)`
- Section dividers styled with `rgb(46, 44, 44)`
